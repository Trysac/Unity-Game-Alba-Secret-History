# Credits

## What the game uses

Everything in the game was made for this project, except the Exo 2 font.

| Asset | Where | Author and licence, or how it was made |
|---|---|---|
| Exo 2 Black and Exo 2 SemiBold (`Exo2-Black.ttf`, `Exo2-SemiBold.ttf`) | `Assets/Fonts` | Natanael Gama (<http://www.ndiscovered.com>), licensed under the [SIL Open Font License 1.1](Assets/Fonts/OFL.txt), Reserved Font Name "Exo". Included unmodified; `Assets/UI/ExoBlack.asset` and `Assets/UI/ExoSemiBold.asset` are font atlases that `ProjectBuilder` rasterises from them, used only to draw text in them. |
| Ground, trees, rocks, standing stones, the keep, lanterns, the portal, pickups, creatures and weapons | `Assets/Scripts/Game` | Built at run time from faceted meshes and noise textures made in code (`MeshFactory.cs`, `TextureFactory.cs`, `WorldView.cs`, `CreatureView.cs`, `CameraRig.cs`) |
| Rain, sparks, ichor, embers, dust and the portal swirl | `Assets/Scripts/Game` | Particle systems set up in code (`Effects.cs`, `WorldView.cs`, `CreatureView.cs`) |
| Materials, particle texture, app icon, scene, UI panel settings, quality and player settings | `Assets/Art`, `Assets/Scenes`, `Assets/UI`, `ProjectSettings` | Generated by `Assets/Editor/ProjectBuilder.cs` |
| Music (title, night, keep and dawn themes), rain and wind loops, and 38 sound effects | `Assets/Audio` | Synthesized by `tools/audio` (Python standard library, encoded with ffmpeg) |
| HUD and menu style | `Assets/UI/Hud.uss` | Written for this project |
| Story, chapter texts and journal pages | `Assets/Scripts/Core/Chapters.cs` | Written for this project |

## The 2021 version

The original *Alba* was a university homework at the Technological University of Peru (UTP).
Its Unity project was never in this repository: it lived on a university SharePoint with an
executable, and it used free Unity Asset Store packages and level music downloaded from
YouTube, as its README said. None of that was used for the rebuild. The repository only kept
seventeen screenshots of it and a text file with the SharePoint and YouTube links. Three of the
screenshots, reduced in size, remain in [`docs/original`](docs/original) as a record of that
version; they show its Asset Store art and are not covered by the MIT licence. The other screenshots and the link file were removed
from the tree; they remain in the git history, which was not rewritten.
